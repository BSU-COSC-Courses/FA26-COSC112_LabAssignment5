# Prime Number Checker

## Due Date

**October 25, 2026, by 11:59 p.m. ET**

## Assignment Overview

Write a Java program that prompts the user to enter a **positive integer** and displays a message indicating whether the number is prime.

A **prime number** is a positive integer greater than 1 that has exactly two factors: **1 and itself**.

## Program Requirements

1. Prompt the user to enter a positive integer.
2. Determine whether the entered number is prime.
3. Display a clear message stating whether the number is prime or not prime.
4. Test your program with multiple inputs, including a prime number and a number that is not prime.
